synthetic-xmp6.heic — provenance
=================================

Generated by scripts/make-heic-exif-only-fixture.py --xmp (run with
`uv run --with pillow-heif ...`; pillow-heif is a dev-time throwaway
encoder, never a repo dependency, same as for synthetic.heic and
synthetic-rot6.heic) for fauxcasa-zq9 review round 1. `--check` verifies
the committed bytes structurally on every preflight run.

This is a SYNTHETIC file — no real camera, no personal data.

The "XMP-only shape": an XMP packet with tiff:Orientation="6", NO EXIF
at all, and NO irot/imir container transform. Encoded with
tiff:Orientation="1" (so the encoder writes no irot), then the single
ASCII "1" in the XMP attribute patched to "6" — same length, no offset
moves.

Structure:
  - Same 96x64 four-quadrant plane as synthetic.heic (top-left red,
    top-right green, bottom-left blue, bottom-right yellow), coded
    96x64, `ispe` 96x64, item properties hvcC/colr/ispe/pixi only.
  - One `mime` item (application/rdf+xml) carrying the XMP packet.
  - No Exif item, no TIFF header anywhere in the file.

What it proves (the review's should-fix): pi-heif's
misc._get_orientation falls through to XMP tiff:Orientation when EXIF
is absent, so in Pillow-plugin mode this file reports
info["original_orientation"] == 6 -- while metareader.read_orientation
(exiv2, EXIF tag 274 only, the value the viewer reports and that
crop_qimage_upright / the face overlay map rects through) reads 1. If
pillowload applied pi-heif's value, grid and viewer pixels would be
rotated while the viewer's reported orientation said 1 and stored-frame
rects would land on rotated pixels. pillowload.heic_manual_orientation
therefore applies exiv2's EXIF read, so this file decodes AS STORED
(96x64, quadrants in stored positions) on every path -- a deliberate,
consistent gap for XMP-only orientation.

Verified by the generating script on every run:
  - pillowload.heif_container_transform(bytes) is False
  - pi-heif standalone decode is 96x64
  - pi-heif plugin mode: original_orientation == 6, no live EXIF tag
  - metareader.read_orientation == 1
  - pillowload.heic_manual_orientation(bytes) == 1 (nothing applied)
